# FP-10 Instrument Box

A web app for the Roland FP-10: switch its built-in tones, transpose, tuning and volume, and play 128 real sampled instruments from its keys over Bluetooth or USB MIDI. Open it in Chrome on Android or on a PC.

Samples:
- `sf2/`: MusyngKite soundfont, [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/), via [midi-js-soundfonts](https://github.com/gleitz/midi-js-soundfonts) (re-encoded to Opus).
- `pro/`: [tonejs-instruments](https://github.com/nbrosowsky/tonejs-instruments) by Nicholaus Brosowsky, [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/) (re-encoded to Opus).
