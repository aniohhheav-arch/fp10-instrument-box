# FP-10 Instrument Box

A web app for the Roland FP-10, over Bluetooth or USB MIDI. Open it in Chrome on Android or on a PC, or install it as an app.

- **Sounds:** the FP-10's built-in tones and GM2 bank, 148 sampled instruments, theremin and synths, layers and splits, scenes
- **Band:** auto-accompaniment in 11 styles that follows your left-hand chords, drum grooves, chord mode, arpeggiator
- **Studio:** effects (distortion, chorus, filter, delay), looper with overdub, recorder with MIDI and audio export
- **Learn:** falling notes for built-in songs or any MIDI file, live chord names, scale highlighting, ear training, practice stats
- **Visualizer** and offline install
