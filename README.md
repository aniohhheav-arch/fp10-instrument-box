# FP-10 Instrument Box

A web app for the Roland FP-10: switch its built-in tones, transpose, tuning and volume, and play 128 real sampled instruments from its keys over Bluetooth or USB MIDI. Open it in Chrome on Android or on a PC.

Samples: FluidR3 GM by Frank Wen, CC BY 3.0, via [midi-js-soundfonts](https://github.com/gleitz/midi-js-soundfonts).
